      PCAI Web v0.2

      「URLを開くだけで篝火ことりに会える」を確認する公開用試作品です。

      • 篝火ことりの人格・口調・昼夜モードを反映
      • Project Chobitsの公式ビジュアル `kotori_master.png` を表示
      • 会話を短期記憶として保存
      • 睡眠処理で長期記憶へcommit
      • ブラウザを閉じても同じ端末なら記憶を継続
      • 記憶のJSON書き出し・読み込みで手動移行

      現在はLLM未接続の会話デモです。実LLM版は秘密鍵をブラウザへ置かないため、次段階で安全なバックエンドを接続します。
