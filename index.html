      PCAI Web v0.3

      Project Chobitsの自然会話LLM接続を、安全な最小構成で検証する公開用試作品です。

      • 篝火ことりの公式ビジュアル
      • Cloudflare Workers AI無料枠による自然会話
      • 本人用アクセス鍵はブラウザ保存しない
      • 直近会話と関連記憶だけをLLMへ送る
      • 会話を短期記憶としてブラウザ保存
      • 睡眠処理で長期記憶へcommit
      • LLM応答だけではPersona Coreを変更しない

      無料AIが利用不能・無料枠超過の場合は有料APIへ切り替えず停止します。
